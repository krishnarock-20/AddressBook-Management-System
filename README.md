📒 Address Book Management System using C
A console-based Address Book Management System developed in C that enables users to efficiently manage contact information. The application provides a simple menu-driven interface for adding, viewing, searching, editing, and deleting contacts while storing data in files for persistence.

🚀 Features
Add new contacts
View all saved contacts
Search contacts by name or phone number
Edit existing contact details
Delete contacts
Store contacts using file handling
Menu-driven user interface
